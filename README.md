# CorpaBot

Бот для дискорд сервера "Корпа".

## Функции

- Создание временных голосовых каналов при входе пользователя в канал с названием `Создать канал`.
- Удаление созданного канала, когда он становится пустым.

## Запуск

1. Установите зависимости при помощи [pnpm](https://pnpm.io):
   ```bash
   pnpm install
   ```
2. Укажите токен бота в файле `.env` или переменной окружения `DISCORD_TOKEN`.
3. Скомпилируйте TypeScript и запустите бота:
   ```bash
   pnpm run build
   pnpm start
   ```

Для разработки можно использовать команду `pnpm run dev`, которая запускает бота через `ts-node`.
