# CorpaBot

Бот для Discord-сервера "Корпа", автоматизирующий работу с временными
голосовыми каналами.

## Как это работает

1. После выполнения командой администратора `/setup` создаются:
   - голосовой канал `Создать канал` — пользователи заходят в него, чтобы
     бот автоматически создал для них личный временный канал;
   - текстовый канал `Управление каналом` с сообщением-интерфейсом и кнопками
     управления.
2. Когда пользователь входит в `Создать канал`, бот создаёт новый голосовой
   канал в той же категории и переносит туда пользователя. Канал получает
   уникальный номер, а создатель назначается его владельцем.
3. Владелец и доверенные пользователи могут управлять своим каналом через
   кнопки в текстовом канале:
   - `🔒` переключает приватность;
   - `✏️` открывает окно переименования;
   - `👥` задаёт лимит пользователей;
   - `🌎` позволяет выбрать регион RTC;
   - `🗑️` удаляет канал;
   - `➕` приглашает пользователя, выдавая доступ;
   - `💥` выгоняет из канала;
   - `⛔/✅` блокирует и разблокирует пользователей;
   - `⭐/❌` добавляет или убирает доверенных пользователей;
   - `👑` передаёт владение каналом.
4. Если канал становится пустым, бот автоматически его удаляет и освобождает
   номер для следующего канала.

## Slash-команды

- `/setup` — создаёт служебные каналы и публикует интерфейс.
- `/interface` — повторно отправляет сообщение с кнопками в текстовый канал,
  если оно было удалено.

## Запуск

1. Установите зависимости при помощи [pnpm](https://pnpm.io):

   ```bash
   pnpm install
   ```

2. Создайте файл `.env` и пропишите в нём `DISCORD_TOKEN=<ваш токен>`. Бот
   использует пакет `dotenv` и автоматически загружает переменные окружения
   из этого файла.

3. Скомпилируйте TypeScript и запустите бота:

   ```bash
   pnpm run build
   pnpm start
   ```

После запуска администратор сервера должен выполнить команду `/setup`, чтобы бот
создал канал `Создать канал` и отправил сообщение-интерфейс.

Для разработки можно использовать команду `pnpm run dev`, которая запускает бота
через `ts-node` и автоматически пересобирает изменения.
