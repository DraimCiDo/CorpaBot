# CorpaBot

Бот для дискорд сервера "Корпа".

## Функции

- Создание временных голосовых каналов при входе пользователя в канал с названием `Создать канал`.
- Удаление созданного канала, когда он становится пустым.
- Команда `/setup` для администраторов создаёт канал `Создать канал` и текстовый канал `Интерфейс` в категории `Голосовые каналы🔊`.
- Команда `/interface` позволяет заново отправить сообщение с интерфейсом управления.

## Запуск

1. Установите зависимости при помощи [pnpm](https://pnpm.io):
   ```bash
   pnpm install
   ```
2. Создайте файл `.env` и пропишите в нём `DISCORD_TOKEN=<ваш токен>`. Бот
   использует пакет `dotenv` и автоматически загружает переменные окружения
   из этого файла.
3. Скомпилируйте TypeScript и запустите бота:
   ```bash
   pnpm run build
   pnpm start
   ```

После запуска администратор сервера должен выполнить команду `/setup`, чтобы бот создал канал `Создать канал`.

Для разработки можно использовать команду `pnpm run dev`, которая запускает бота через `ts-node`.

## Активность через DiscordSDK

Для показа активности в клиенте Discord с помощью Discord Game SDK выполните следующие шаги:

1. Установите зависимость `discord-gamesdk` и соответствующие бинарные файлы SDK. Инструкция приведена в [docs/discordsdk-activity.md](docs/discordsdk-activity.md).
2. Укажите `DISCORD_CLIENT_ID` в `.env` и скомпилируйте проект.
3. Запустите скрипт активности:
   ```bash
   pnpm run build
   pnpm run activity
   ```
4. При корректной настройке в профиле пользователя будет отображаться кастомная активность.
