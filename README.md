# CorpaBot

Бот для дискорд сервера "Корпа".

## Функции

- Создание временных голосовых каналов при входе пользователя в канал с названием `Создать канал`.
- Удаление созданного канала, когда он становится пустым.

## Запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Укажите токен бота в переменной окружения `DISCORD_TOKEN`.
3. Запустите скрипт:
   ```bash
   python bot.py
   ```
